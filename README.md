# Pokalschießen App v65

Änderungen gegenüber v64:
- Telefonnummer ist optional und wird bei leerem Feld nicht auf den Schießzettel gedruckt.
- Nach Auswahl der Schießart wird das Feld für die erste Scheibennummer aktiv und erhält sofort den Fokus.
- Die erste Scheibennummer bleibt Pflicht für jeden Satz.
- Vorlage und gespeicherte Positionen wurden nicht verändert.
- Druckmechanismus bleibt wie in v64.
