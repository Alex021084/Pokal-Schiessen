# Pokalschießen – Redesign v15

- Im Preisscheiben-Fenster ist Doppeltipp-Zoom auf dem Mengenbereich und den Plus-/Minus-Tasten deaktiviert.
- Schnelles mehrfaches Tippen auf + oder − verändert weiterhin zuverlässig die Scheibenanzahl.
- Pinch-Zoom außerhalb des Mengenfensters bleibt möglich; die allgemeine Seitenzoom-Bedienung wird nicht pauschal abgeschaltet.
- Alle bisherigen Funktionen aus Version 14 bleiben erhalten.
